# Snake Water Gun Game 🐍💧🔫

A fun Python implementation of the classic Snake-Water-Gun game (similar to Rock-Paper-Scissors).

## How to Play
- s for Snake
- w for Water  
- g for Gun

Rules:
- Snake drinks Water (Snake wins)
- Water drowns Gun (Water wins)
- Gun kills Snake (Gun wins)

## How to Run
python project.py

## Tech Used
- Python 3
- Random Module
